# yt-ad-platform

Marketing site for WEB3TASK, a YouTube advertising platform for creators and businesses. Built with Next.js (App Router) and GSAP.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Where things are

- `app/page.tsx` — home page
- `app/case-study/` — ad format and campaign guides (list and detail pages)
- `app/contact-us/` — contact page
- `app/data.ts`, `app/case-studies.json` — page copy and guide content
- `app/components/Motion.tsx` — all GSAP scroll and load animation
- `app/globals.css` — styles
